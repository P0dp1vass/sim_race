# VAR-02 — Единый словарь параметров сетапа

## Назначение

Канонический технический идентификатор — точное имя поля из файла Фёдора. Русское название — единая подпись для интерфейса и API. Разные колёса и стороны машины не объединяются в один регулируемый параметр. В ответе API поле `parameter` использует русское каноническое название из таблицы.

## Правила использования

1. `parameter_id` / `parameter_key` в правилах ссылается на точный технический ID из первого столбца; `parameter` в API — точное русское имя из второго.
2. Для рекомендаций выбирать только регулируемые параметры. Вычисляемые (`cross_weight_pct`, нагрузки на колёса, высота кузова и т. п.) можно использовать как эффект или контекст, но не как непосредственную цель изменения.
3. Не сводить `lf`, `rf`, `lr`, `rr` в один параметр: диапазоны, стороны и направление воздействия отличаются.
4. Диапазоны, шаги, варианты `enum` и зависимые ограничения брать из исходного файла Фёдора, не копировать их в словарь: они зависят от конфигурации.
5. Не использовать русские названия для машинного поиска; искать по техническому ID. Пользовательские синонимы симптомов хранятся в экспертных правилах отдельно.
