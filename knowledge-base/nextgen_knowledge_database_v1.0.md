# База знаний по настройкам NASCAR Cup Series Next Gen (Gen 7) — теория и практические гипотезы

Версия: 0.2  
Назначение: зафиксировать **(1) что физически/технически меняет параметр** и **(2) какое влияние на поведение машины прямо описано в источниках**.  
Практические направления «увеличение/уменьшение → ожидаемый эффект → фаза поворота» приведены как гипотезы для проверки, а не как подтверждённые универсальные правила.

## Правила заполнения

- **Что меняет параметр:** назначение параметра или непосредственное изменение, подтверждённое руководством.
- **Теоретическое влияние на поведение:** только явно описанный источником эффект на баланс, сцепление, устойчивость, реакцию машины или работу подвески.
- **«Не указано» не означает «эффекта нет».** Это означает, что в проверенных источниках нет достаточно конкретного утверждения для этого поля.
- Не переносим автоматически эффект с передней оси на заднюю или с другой машины/класса на Next Gen.
- Если источник описывает эффект только при чрезмерной настройке, это условие указано отдельно.
- Значения диапазонов и шагов берутся из `nextgen_values_parameters.md` (SRC-07). Этот файл описывает доступные значения, но сам по себе не доказывает физический эффект.
- Основной источник поведения для Next Gen: **NASCAR Next Gen Cars User Manual V2**, разделы Advanced Setup Options. Дополнительный источник: **iRacing Car Setup Guide (2010)**. Если эффект есть только в общем руководстве, это прямо отмечено; применимость к конкретной настройке Next Gen требует осторожности.
