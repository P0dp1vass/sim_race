# VAR-01 — Каталог технических источников

## Каталог источников

| ID | Источник | Назначение |
|---|---|---|

| SRC-04 | [iRacing — Setup: A Beginner’s Guide](https://support.iracing.com/support/solutions/articles/31000168572) | Только раздел «Useful setup guides»: ссылки на полезные руководства по настройке сетапа. |
| SRC-05 | [iRacing — 2026 Season 1 Patch 3 Release Notes](https://support.iracing.com/support/solutions/articles/31000178020-2026-season-1-patch-3-release-notes-2026-02-02-02-) | Патч-ноуты; дополнительная информация об обновлениях симулятора, не основной технический источник для правил. |

## Соответствие параметров источникам

| Группа параметров | Источники |
|---|---|
| Давление шин (LF, LR, RF, RR) | SRC-01, SRC-03, SRC-07 |
| Баланс тормозов и тормозные цилиндры | SRC-01, SRC-07 |
| Передний и задний стабилизаторы (ARB), преднатяг | SRC-01, SRC-07 |
| Пружины, высота подвески, регулировка опор амортизаторов | SRC-01, SRC-07 |
| Амортизаторы: compression/rebound, LS/HS | SRC-01, SRC-07 |
| Развал, кастер, схождение | SRC-01, SRC-07 |
| Распределение веса (cross weight, corner weight) | SRC-01, SRC-07 |
| Актуальность значений и доступных настроек | SRC-07; SRC-05 и SRC-06 — дополнительные сведения об обновлениях |

## Примечание

Основной источник для экспертных правил — **SRC-01**. Файл **SRC-07** используется как рабочий перечень параметров и значений для NASCAR Next Gen, но сам по себе не является независимым подтверждением физических эффектов. Перед присвоением правилу статуса «разрешено к выдаче» необходимо проверить конкретное утверждение по техническому источнику и, при необходимости, в актуальной версии iRacing (FED-05).
